## Про проєкт

**Polyglot-translate** — це оновлена версія сайту бюро перекладів, що приймає замовлення на письмові та усні переклади документів будь-якої тематики. Сайт повністю перероблений: нова структура, сучасний дизайн, адаптивність під усі пристрої та зручна форма замовлення з відправкою на пошту.

Робочі мови: **українська, англійська, німецька, польська, іспанська, італійська** — і ще понад 60 мов світу.

---

## Що нового в цьому оновленні

- **Новий сучасний дизайн** — перероблена шапка, головний екран із фоновим відео та секції сайту.
- **Повний редизайн на SCSS** — модульна архітектура стилів (`layout`, `components`).
- **Слайдер відгуків** на базі Splide.js з адаптивними налаштуваннями (3→2→1 колонка).
- **Адаптивність** під планшети та мобільні пристрої.
- **Оновлена форма замовлення**: валідація телефону за українським форматом `380XXXXXXXXX`.
- **Бекенд на PHP** — заявки з форми відправляються на email, окрема сторінка успішної відправки.
- **Поліпшений футер** з посиланнями на соцмережі та email.
- **Кнопка «нагору»** для швидкої навігації.

## Секції сайту

1. **Головна** — екран із фоновим відео та закликом «Замовити переклад».
2. **Переклади** — картки послуг: письмовий, усний переклад, бізнес-листування.
3. **Мови** — прапори та перелік робочих мов.
4. **Про нас** — статистика: 1500+ перекладів, 2000+ клієнтів, 24/7 онлайн.
5. **Відгуки** — слайдер із відгуками клієнтів і рейтингами.
6. **Зробити замовлення** — контактна форма з відправкою на email.

## Структура проєкту

```
polyglot-website/
├── index.html            # Головна сторінка сайту
├── success.php           # Сторінка успішної відправки

│   ├── main.scss         # Точка входу стилів
│   ├── layout/           # Змінні, міксіни, контейнери

├── js/                   # Скрипти сайту та бібліотеки
├── images/               # Графіка, прапори, іконки, відгуки
└── video/                # Фонове відео головного екрана
```

## Запуск

Оскільки на сайті є PHP-бекенд, рекомендується запускати через локальний сервер:

```bash
# PHP вбудований сервер
php -S localhost:8000
```

Потім відкрийте у браузері `http://localhost:8000`.

**Без бекенду** — достатньо відкрити `index.html` у браузері; форма не буде надсилати заявки.

> Перед деплоєм вкажіть свою email-адресу отримувача у файлі `form-send.php`.
