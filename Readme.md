## Про проєкт

**Polyglot-translate** — сайт бюро перекладів, що приймає замовлення на письмові та усні переклади документів будь-якої тематики.

Робочі мови: **українська, англійська, німецька, польська, іспанська, італійська** — і ще понад 60 мов світу.

https://rusprogger.github.io/Polyglot2/

---

## Що нового у версії 2.1

- **Відгуки від клієнтів** — кнопка «Написати відгук» по центру секції, модальне вікно з полями ім'я, коментар і оцінка від 1 до 5 зірок.
- **Відгуки зберігаються на сервері** — вони з'являються в слайдері одразу після надсилання, залишаються після перезавантаження сторінки і видно з будь-якого пристрою.
- **Капча** — власна, без зовнішніх сервісів: сервер генерує код на картинці (4 символи, шумові лінії та точки). Якщо на хостингу немає GD — автоматично показується приклад `4 + 7 = ?`.
- **Захист від спаму** — ліміт 5 відгуків на годину з одного IP, пастка для ботів, захист від повторного відгуку, обмеження кількості записів у базі.
- **Слайдер перераховує точки** автоматично, коли з'являється новий відгук.

## Як працюють відгуки

### Запити

| Запит | Опис |
| --- | --- |
| `GET reviews.php` | Повертає всі відгуки, нові — першими |
| `POST reviews.php` | Зберігає новий відгук, повертає його у відповідь |
| `GET captcha.php` | Віддає налаштування капчі (картинка або приклад) |
| `GET captcha.php?img=1` | Малюнок капчи, код зберігається у сесії |

### Збереження

Відгуки пишуться у `data/reviews.json`. Завдяки цьому вони:

- залишаються після перезавантаження сторінки;
- однакові для всіх відвідувачів і всіх пристроїв;
- не залежать від браузера користувача.

### Захист

| Захист | Реалізація |
| --- | --- |
| XSS | `strip_tags()` на сервері + `textContent` у JS при виводі |
| Спам у вигляді HTML | `strip_tags()`, прибирання керуючих символів, стискання пробілів |
| Боти | прихована пастка-поле (`website`) |
| Флуд | не більше **5 відгуків на годину** з одного IP (IP зберігається лише як SHA-256 хэш) |
| Повтори | однаковий текст не частіше ніж раз на хвилину |
| Розмір бази | максимум 500 відгуків, найстаріші автоматично витісняються |
| Підміна коду капчі | порівняння через `hash_equals`, код одноразовий, TTL 10 хвилин |
| Прямий доступ до JSON | `data/.htaccess` закриває перегляд файлу в браузері |

## Запуск

Сайт має PHP-бекенд, тому його не можна відкрити подвійним кліком — потрібен локальний сервер:

```bash
# Вбудований сервер PHP
php -S localhost:8000
```

Далі відкрийте `http://localhost:8000`.

> Відгуки **не працюють** без PHP — це навмисно, вони зберігаються на сервері.

## Деплой на хостинг

1. Залити всі файли на сервер.
2. Виставити права на папку `data` — `755` або `775`, щоб PHP міг у неї писати.
3. Перед першим запуском переконатися, що `data/reviews.json` існує (можна порожній `[]`).
4. Вказати email отримувача у `form-send.php` (змінна `$to`).
5. Перевірити, чи увімкнені сесії та GD:

```bash
php -r "var_dump(function_exists('imagecreatetruecolor'));"
```

`true` — буде картинка, `false` — автоматично з'явиться приклад.

> **Увага, nginx:** файл `data/.htaccess` працює лише на Apache. На nginx доступ до `data/reviews.json` краще закрити вручну у конфігурації сервера.
